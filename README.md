# antl — E-commerce Template 03

Template e-commerce React/Vite/TypeScript inspiré de la maquette Figma « Modern-Retro Beverage Brand ».

## Inclus

- Catalogue, panier et total front persisté localement
- Sections de page, produits et marque configurés dans `src/content/commerce.ts`
- Visuel produit local dans `src/assets/`
- Écran 404 avec `HashRouter` et configuration GitHub Pages
- Paiement volontairement inactif : exporter `antl-site-payments` puis configurer le compte Stripe du client avant tout encaissement

## Démarrer

```sh
npm install
npm run dev
npm run build
```

Le contenu, les prix de démonstration et l'ordre des sections sont des placeholders à remplacer pour chaque client.
